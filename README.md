# Игра с гоблинами (AHJ — Обработка событий)

![Build Status](https://github.com/jusnd/ahj-events/actions/workflows/deploy.yml/badge.svg)

**GitHub Pages:** https://jusnd.github.io/ahj-events/

Домашнее задание к занятию «3. Обработка событий» курса AHJ (Нетология).

## Описание

Игра «Поймай гоблина»:

- гоблин появляется в случайной ячейке поля 4×4 ровно на 1 секунду;
- если успеть кликнуть по ячейке с гоблином — засчитывается +1 балл, гоблин пропадает;
- курсор над полем заменён на кастомный курсор в виде молотка;
- если пропустить 5 появлений гоблина — игра завершается с показом итогового счёта.

## Структура проекта

Приложение разбито на классы, каждый отвечает за свою часть логики:

- `src/js/Board.js` — игровое поле: сетка ячеек, появление/исчезновение гоблина;
- `src/js/Game.js` — игровая логика: таймер, подсчёт попаданий/промахов, конец игры;
- `src/js/ScoreBoard.js` — панель счёта и экран завершения игры;
- `src/js/app.js` — точка входа, связывание компонентов.

## Технологии

- Менеджер пакетов — **yarn**
- Сборка — **Webpack** (JS, CSS, картинки)
- Деплой на GitHub Pages — **GitHub Actions** (`.github/workflows/deploy.yml`)

## Запуск локально

```bash
yarn install   # установка зависимостей
yarn start     # dev-сервер на http://localhost:9000
yarn build     # production-сборка в папку dist/
```
